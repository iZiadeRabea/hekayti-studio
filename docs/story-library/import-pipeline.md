# Reusable creative import pipeline

Source → Metadata → Summary → DNA → Pattern → Family → Age → Culture → Candidate → Validation → Import.

The source pipeline is not an automatic whole-story generator. Source-derived IDEA_SEED is valid when no complete canonical outline is justified. Preserve sparse evidence; no title-to-plot invention. Full imported canonical candidates continue through the existing manual bridge, Blueprint, language editions, QA and exact human approval with no stock mock replacement.

Native JSON/JSONL picker: strict version1 GENERATED records; unique IDs; no operational package/import authority or APPROVED_STORY_REFERENCE creation. Max10000 records/25MB. Logical Unicode is required throughout metadata, DNA and localized content; bidi controls rejected. Validation is one atomic batch/CAS save, not5000 individual inserts. Exact first-revision identity replay is idempotent; different payload under an existing ID is a readable conflict. No overwrite/hard delete.

SQLite v3 gains an additive library-index/1.0 cache and marker, without changing old aggregate bytes, workflow1.0/1.1 or prior generation-package hashes. Indexed bound SQL handles paged search/filter; full mirror consistency is verified against canonical aggregate before filtering. Validation is linear in retained revisions; only at most100 result records/30 UI rows are returned/rendered. The10000-revision aggregate bound remains, so this is measured5000 scale, not unlimited storage.

Public batch APIs do not fetch websites or upload private data. Full-source collection is an explicitly authorized cached research operation; consumer model interaction remains manual. Unknown context IDs cannot be silently dropped by the bridge UI.
