# Story QA
D release checklist. Automated lint later assists; native/qualified human review remains required. Research-based profile version and reviewer scope must be traceable.

BLOCKER: unsafe content/privacy leakage, unresolved consent, incoherent essential causal chain, wrong age eligibility, medical/therapy guarantee, stale/unapproved source.
MAJOR: excessive age complexity, unexplained cast/props, goal changes, confusing language/register/localization; no release until corrected.
MINOR: optional wording/style polish; owner may defer with recorded reason, never downgrade a safety issue.

Check actual story word/page totals and sentence/clauses against soft AgeProfile guidance; investigate overruns rather than auto-cut. No infant plot mandatory; no independent-literacy assumption. One coherent objective, concrete progression, repetition varied where appropriate, supported emotions, no shame/threat reward dependence.

Native read-aloud review: rhythm, pronounceable names, age register, speaker attribution, diacritics/spelling, MSA versus Egyptian voice. Localization compares meaning by beat/page, including object quantities, causality, emotion and page-turn reveal. English not literal replacement.

Continuity: before/after state, clothing, carried objects, location/time transition, character knowledge, ending payoff. Page named action is illustratable and agrees with image contract. Parent notes separate and optional, no intrusive quizzes.

Report findingId/severity/pageOrBeatId/evidence/recommendation/reviewer/status/fixRevision; uncertainty labelled. External source accuracy/sensitive themes routed to qualified review. An AI simulated panel is advisory, not consented Egyptian child testing.

Phase2 acceptance fixtures: age boundaries/unknown, disallowed under-two video, unsupported age96+, optional hero, glossary/dialect drift, text–image mismatch, invalid refs and upstream edit staleness. Phase1 checks only document/example consistency; no generated stories clinically validated.
