# Book and video delivery QA
Separate checklists per output; one good preview does not approve all derivatives.

## Print

Every page/matter role present in correct reading order, no unintended duplicate/blank/missing asset, final count matches binding. Trim/Bleed/Safe/gutter validated against actual printer profile; cover-wrap correct for stock/page count/right binding. Effective placed image PPI; licensed font embedding; PDF standard/ICC transparency requirements; no body text overflow/diacritic clipping, glyph reversal or text over faces.

Native Arabic reads connected/logical; mixed numerals/English/punctuation reviewed. Correct edition mode and spelling, actual title/credits; no invented ISBN/legal assertions. Render all pages, full human review and physical proof. Fail if printer profile/proof missing for sale.

## Digital

Lightweight profile not print marks/bleed; order consistent with canonical, text selectable, accessible reading order and metadata where supported, honest accessibility limits. Two actual reader/device tests, zoom readability/marks/crop/links, file size/hash and correct delivery version. No embedded child names in file paths/metadata without private approval.

## Video

All required beat/shot refs approved; match language narration/caption timing, speech intelligibility, rights music/SFX/fonts, safe slow motion/no flashes, no extra story events, finite ending. Full playback and target-player test for Arabic captions/encoding/aspect ratio. Under-two child viewing gate holds; co-viewing message not autoplay promotion.

## Shared release conditions

Exact dependency hashes, no stale inputs, QA record scope/reviewer/date, privacy/consent check, owner export approval. Synthetic fixture PASS is not a printer/guardian production sign-off. Export failures retain old approved file and show candidate failure; never silently deliver partial output.

Evidence: preflight report, rendered page set, marked findings, print proof approval and video playback record. No final export produced in Phase1.
