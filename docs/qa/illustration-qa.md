# Illustration QA
Human approval on every final page; future automated validators check format/dimensions/hash/refs, not artistic truth.

BLOCKER: child sexualization/unsafe imagery/PII leakage, unintended anatomy artifacts, wrong approved character, missing story-critical action/object, inappropriate copyrighted IP.
MAJOR: clothing/proportion/style/palette drift, wrong prop count/state, mixed environment anchors, text region obstructed or unsuitable crop.
MINOR: noncritical decorative variance allowed only if whole-book style remains coherent.

Compare exact CharacterBible/StyleProfile and approved references, intended anatomy including disability/species, hair/skin/clothing/accessories; don't use unsupported biometric identity scoring. Hands/limbs connect and occlusion/action makes sense. Environment anchors continue within scene; transferred props move once, no reset/disappearance/duplicate.

Paper material/layer/shadow/lighting consistent; no photographic/plastic faces. Focal action/emotion readable at output size, age density appropriate, quiet text rectangle preserved and safe crop tested. Validate literal visible noun/action contract, deliberately nonliteral metaphors explicitly labelled. No generated body text or unexplained signs/watermarks.

Reject candidate → record page/asset/finding → smallest targeted regeneration/edit → compare neighbours → owner approves new immutable asset/pointer. Old assets preserved. Common root causes addressed at plan/bible level, not hidden beneath text/crop.

Final approval records asset hash, bible/style/source versions and reviewer. Correct dimensions/resolution alone never equals illustration PASS.
