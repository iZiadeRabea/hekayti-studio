# Image prompt foundation

GENERATE retains character-reference descriptions first, then a cover based only on the actual opening action and every canonical page. Full fixed character definitions repeat in page prompts. Arabic human summaries retain the real page text and localized state; optional technical prompts may contain English labels/JSON under disclosure. No provider superiority or execution evidence is claimed.

Default paper-cut/collage uses tactile paper, layers, soft shadows and child-friendly composition. Palette is flexible while wardrobe colors stay fixed. Local soft watercolor is optional. Global negatives always apply: no text even on the cover (title added later), watermark/logo, unexpected cast, clothing/prop drift, fear/violence/punishment or photorealistic children. Human anatomy rules apply to humans. Appearance defaults are explicitly synthetic proposals, gender is never inferred from names, and no real photos are used.

Before a future manually approved trial, review the character reference, reconcile authored appearance with the visual bible and confirm unknown visual details. Prepared/copied descriptions are not images, native/literary approval or verified illustration consistency.
