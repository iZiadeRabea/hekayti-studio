# Illustration plan — prompt foundation only

The local service uses the current imported canonical draft, exact edition/pages, accepted story plan and retained Blueprint. It does not split, rewrite or invent a story. Each page keeps identity/order, beat references, actual actor/quality-participant cast, original narration/dialogue, localized action/before/after state and bounded known props. Unspecified expression, hand pose, size, framing and placement remain review proposals. Arbitrary prose details are not certified by lexical extraction.

`illustration-plan/1.0` binds draft, Blueprint, accepted plan, visual bible and style revisions/hashes. Edits append revisions; old prompts remain readable but are labeled stale. PREPARE/GENERATE/COPY revalidate creator/planner/workflow CAS and dependencies; stale COPY/GENERATE fails closed. Read-only loading neither changes state nor touches the clipboard. The owner synthetic 42-month fixture produces 12 exact canonical pages, not a generic twelve-scene template.

Additive sealed SQLite v4 creator storage validates historical source links and prompts. It is operational data excluded from creative Library recovery. Old plan/draft/workflow schemas and hash history are unchanged; 791 corpus unchanged. No image generation, provider/API/browser execution, asset approval or layout/export occurs.
