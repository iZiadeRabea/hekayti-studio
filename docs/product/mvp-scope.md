# Strict MVP scope
Owner tool, Windows local-first, Egypt. Initial useful slice is one synthetic short Arabic picture book; later V1 complete means all three product paths tested, not all features delivered at once.

## MUST HAVE for complete internal V1

- Projects with age/months, category, language/objective, status and recoverable versions.
- Versioned canonical blueprint, Age Engine guidance, primary MSA/Egyptian language editions, manual editing/import.
- Approval gates and stale dependency warnings; simple project wizard/editor.
- Character/style reference locks, page planning, illustration import and a single approved provider adapter if chosen.
- Full-book preview, provider-profile print PDF and lightweight digital PDF, Arabic RTL/render QA.
- Basic eligible illustration-based video storyboard, narration import, captions and deterministic assembly; no whole-video AI dependency.
- QA checklists, provenance/cost logging without PII, finite job retries/cancel/resume.
- Source-code recovery retained; separately approved secure operational-project backup/restore for real orders before selling.
- Personalization optional; level0 synthetic/stock first. Name/preference/hero levels1–3 only after private-data gates; no photo mandatory.
- Local installer/manual update safety and migration backup; not multi-user hosting.

## SHOULD HAVE (after reliable first slice)

Reusable story/type templates, batch approval of already reviewed items, comparison view, text search, audio read-aloud assistance, polished error recovery, useful activity/parent pages. English localization if demand/quality warrants, not machine translation as final.

## LATER

Level4 photos after privacy/provider/consent gate; provider choices, more ages, bilingual editions, EPUB/accessible advanced formats, generative short-shot animation, richer voices, character catalogue, packaging/signing automation.

## NOT IN V1

Customer accounts, payment checkout, public ordering website, online photo portal, autonomous one-click publishing, public child gallery, face recognition/voice cloning, school integration, therapeutic diagnoses, analytics on children, marketplace launch automation.

## Definition of usable / launch gate

Synthetic A/B/C story specs reviewed at intended ages; every delivered artifact traces to one approved revision. At least one printer proof accepted, digital open/read tested, eligible video fully reviewed, restart/failure/migration/private-project recovery rehearsed and real-data controls signed off. Quantitative word/page budgets evaluated, not merely validator-green.

A/B infant video is ineligible: testing the block is part of coverage, not generating infant video. No commercial customer validation or production readiness asserted by Phase1 docs. Owner agrees schedule/cost/hardware and release acceptance before implementation.
