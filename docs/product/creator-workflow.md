# Owner-operated creator workflow
D: controlled publishing, not one-click generation. No customer UI in V1.

| Stage | Owner activity / human approval | Saved evidence / failure route |
|---|---|---|
| 1 Intake | Order brief: exact months, mode, type, one objective, output intent, personalization | Draft record; missing info asks owner; private input outside source |
| 2 Eligibility | Review AgeProfile and screen/privacy gates | Reasons/safer alternative; hard gate cannot silently bypass |
| 3 Concept | Choose concept/goal/cast, approve meaning | concept-approved revision; rejected ideas retained |
| 4 Blueprint | Review beats/cause/state/page budget | plan candidate, resolve warnings; no art cost yet |
| 5 Language | Native text edit/read-aloud and objective/safety review | edition approval; semantic changes return to concept/plan |
| 6 Page plan | Approve layout roles, text/visual contract and final story sequence | page IDs and constraints |
| 7 Characters/style | Owner/guardian where relevant approves illustrated bible/reference | version locks; photos require separate gate |
| 8 Art pilot | Approve key interior/cover/style before paid batch | cost threshold and asset candidates |
| 9 Illustrations | Review every candidate for continuity | approved asset refs; regenerate one page if necessary |
| 10 Book preview | Review complete book in selected profile | layout approval; overflow stops export |
| 11 Video optional | Review eligible shot plan, narration, motion/captions | separate adaptation approval; no infant child-viewing |
| 12 Export | Preflight, full playback/PDF review, physical print proof when required | export-approved per output; manual delivery |
| 13 Close | Record delivery version and private retention tasks | audit stub; production-data backup only under approved policy |

Approvals bind exact hashes/revisions, not permanent checkboxes. An upstream change visibly marks downstream artifacts stale; export refuses stale required approvals. UI later shows next required action, blockers, cost state and retry choices.

Manual editing/import is a first-class fallback when provider unavailable; user can continue local text planning without network. No automatic provider substitution with private data. Paid action explicitly scoped/confirmed; generation cancellation and failed/uncertain job reconciliation clear.

Jobs resumable, exports immutable, old revisions never deleted by regeneration. Expert/native/guardian roles can be owner-assisted but qualifications/approval scope must be honest. No AI self-approval standing in for human review.
