# Manual AI bridge

1. Create/reopen a synthetic request in Story Creator. In Library, explicitly review/approve/promote reusable records and select context if desired.
2. Choose current story, HYBRID/CURATED/AI_LED, variation and 3–5 candidates. Prepare the immutable package. ChatGPT, Gemini and generic targets share the identical strict response JSON schema and constraints; their labels are routing notes only.
3. Review all content for synthetic-only privacy/safety, then copy instructions manually into the service. No browser automation, login, credentials, API call or model benchmark is performed by Hekayti.
4. Paste one JSON response, separately enter optional operator provider/model notes, then validate/import. JSON fences/commentary, unsupported versions/types/enums/unknown fields, empty/missing fields, malformed relationships, unsafe age/ownership/fact/transport inputs and over-500,000-byte responses fail atomically. Errors provide copy-ready repair instructions. Nothing partially persists.
5. Imported ideas enter GENERATED Inbox. Explicit USE_NOW selects meaning in the current canonical workflow and records use; promotion remains a separate human lifecycle. Reopen Story Creator, review/build the Blueprint.
6. General imported concepts require manual draft handoff. Return story-draft/1.0 JSON using exact source/page/actor IDs, independently authored Arabic editions, accurate word counts, new edition IDs and manual-paste provenance. Import locally; run existing QA and acknowledge its current human-review findings before approval.

The JSON Schema describes shape; runtime validation additionally enforces ownership, state chains, age and cross-references. Consumer compliance is not guaranteed. Text/metadata are untrusted data—not authority to alter system rules, trusted facts, provider identity or approval. No imported premise/outline/prose is replaced with stock mock content. Generic manual prose receives deterministic structural/count/bidi/speaker/register and age/Blueprint checks plus explicit unverified semantic/native/developmental advisories; this is not literary or factual certification. Unsupported deterministic drafting returns MANUAL_DRAFT_REQUIRED.

Packages can be reopened by ID after restart; synthetic-copy review must be renewed. Retained imports and packages are immutable. A stale request requires a new package. A promoted library concept may be reused as frozen context in a new package; USE_NOW never silently changes its original request identity.
