# Phase 3 component registry

`ideaComponents` provides independently reusable theme, objective, setting, character archetype, mechanism, challenge, conflict, discovery, resolution, emotional goal and educational goal choices. Components contain choices rather than whole manuscripts. Request theme/objective and approved age structure determine composition; generation rotates objects, settings and eligible mechanisms. Synthetic preferences influence object selection without changing the requested objective.

This is a bounded mock: only authored semantic action/state combinations are supported. Unsupported mechanisms fail readably. Source preference (including AI) is separate from actual mock provenance. No provider calls, private input or literary approval occur.
