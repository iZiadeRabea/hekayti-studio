# Deterministic concept generation

`createConceptSet(request, structure, generation)` validates strict inputs and returns three candidate concepts tied to the exact request revision. `MockStoryConceptProvider` is the asynchronous adapter. Identical inputs produce identical outputs; the generation counter rotates meaningful mechanism/action/object/location combinations.

Mechanisms have authored micro-action sequences, not interchangeable story labels. Recognition/reveal/sound-play retain familiar recognition units. Routine/helping are supported routines; older discovery, problem solving, cooperation, journey, mystery, treasure hunt and building use bounded action sequences. Canonical before/after states describe each visible result. Localized focus is a concrete noun and detail is a locative adjunct. Language realization must preserve action and result, not infer missing events.

Name-only personalization does not create a protagonist. Level 3 explicitly names the synthetic protagonist; known fictional archetypes carry authored grammatical agreement, while unknown personalized agreement remains unspecified. Arbitrary objectives remain preserved but require explicit human fit review; mock generation does not certify success.
