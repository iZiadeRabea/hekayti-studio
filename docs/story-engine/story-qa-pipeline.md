# Structured advisory QA

`reviewStoryBlueprint` reports strict validation, request ownership/objective, canonical meaning drift, state continuity, uncovered pages, character bible changes, concrete art requirements and reviewed fact evidence. Placeholder prose is an explicit high finding. Preaching, emotional support, ending payoff, native voice and developmental quality require human reading rather than keyword certification.

Reports use structured severity/category/location/message/suggestedAction findings. `StoryQaReportSchema` requires a revision, SHA256 content hash and `humanReviewRequired: true`. Automated findings do not mint human approvals. Actual approval remains the existing separate hash/revision-bound workflow. All tests here use synthetic inputs; no production, visual or clinical acceptance is asserted.
