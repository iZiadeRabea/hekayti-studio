# Story type catalogue
All suitability below is D editorial guidance, interpreted with the Age Engine. One primary category and optional secondary tags; personalization is an orthogonal mode, not a competing plot genre. Ages are opportunities, not promises of learning/behaviour change.

| Type | Purpose / ages and limits | Structure / tone / learning | Themes / example concept | Common mistake |
|---|---|---|---|---|
| educational | Explore one observable idea; 2+ contextual, younger sensory only | Notice → try → visible result; curious, concrete | Float idea using adult-led safe scene; big/small sorting | Lecture, many lessons, false science |
| behavioral | Model an achievable action; 1+ routines, mature self-control not assumed | Trigger → supported practice → retry; warm | Put a toy in basket; ask for a turn | Shame, punishment, claims to cure behaviour |
| values | Demonstrate care/fairness; mostly3+, simple helping younger | Choice → consequence → repair; non-preachy | Two friends make room on a bench | Abstract moral slogan, obedient hero only |
| everyday-life | Familiar transitions; all bands adapted | Predictable routine or recognition sequence | Hello, dressing, visiting a relative | Calling ordinary frustration badness |
| bedtime | Calm connection; all bands with adult reading | Gradual settling, gentle refrain, reassuring ending | Animal friends say goodnight | Claim to treat sleep, frightening cliffhanger, screen-first bedtime |
| emotional-learning | Name and support feelings; 2+ concrete, warm faces younger | Feeling → noticing → supported coping → reconnect | Fox frustrated when tower falls | Therapy claims; emotion instantly disappears |
| adventure | Bounded exploration; 2–3 tiny supported form, 3+ fuller | Goal → few attempts/clues → choice → safe return | Bird finds where garden sounds come from | Infant quest, peril, villain complexity, child alone in danger |
| discovery | Notice an observable surprise; 1+ recognition,3+ explanation | Question → observe → compare → find | Find which object makes a soft sound | Unsupported fact, reveal not shown in art |
| early-learning | Familiar sounds/objects then shapes/counting; all adapted | Name → repeat → one variation | One ball appears in different safe positions | Worksheet overload, infant academic mastery |
| personalized | Optional identity/preferences/hero overlay on another primary category; all adapted | Keep chosen structure and objectives; approved insertion | Fictional child name in dedication, or optional hero | Treating every customer child as protagonist; storing private input in Git |

## Category and objective rules

Educational = knowledge/concept; behavioral = observable supported action; values = action expresses social principle; emotional = naming/handling a feeling. Pick one primary objective; secondary objectives cannot overfill an age budget. Child is never told their purchased story diagnoses or fixes them.

Not suitable at any age: sexualized children, graphic violence, discriminatory stereotypes, fear/threat obedience, medical treatment instructions, dangerous copyable stunts. Sensitive topics (loss, illness, disability, faith) require specific qualified/cultural review; do not auto-generate from a generic label.

Conventional setup/problem/resolution is optional for early concept books. Use gentle recurrence and recognition instead. Adult assistance is developmentally respectful; do not apply adult-fiction “hero must solve alone” dogma.

Eligibility output includes reasons, safer alternative and human review status. Rejecting an under-one adventure proposes an object/face discovery sequence, not a “failed child” message.
